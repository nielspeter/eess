**Breaking (@nielspeter/eess-md):** `honestyAtClose` reports two state lines that disagree (bug 0623). Two lines that agree read as before. A corpus with such a record can newly go red. The state/folder check reports it before reading either line; the box checks still read the first, so keeping one state can bring out a box finding. To migrate: keep the one state the record means; if the second line is prose that opens with the label (`State: kept in Redis`), reword it, as the finding's remedy says. `findState` is unchanged and still returns the first state line; its documentation now says how its reading differs from `haveField`'s.
